# cpp-tax-calculator
Collaborative final C++ project for a college course. Simulates a U.S. income tax calculator designed to calculate estimated federal and state income taxes.

## Project Overview

This program prompts the user for:

- Gross annual income
- Filing status (Single or Married)
- State of residence

The application then calculates:

- Estimated federal income tax
- Estimated state income tax
- Total tax amount
- Estimated take-home pay

Tax calculations are based on progressive federal and state tax bracket data stored within the program.

---

## Features

- Federal tax calculations
- State tax calculations for all 50 U.S. states
- Progressive tax bracket system
- Input validation for:
  - Income
  - Filing Status
  - State names
- Organized data structures using structs and vectors
- Formatted tax summary output
