# How to Use cpp-tax-calculator

1. Download the `main.cpp` file.

2. Open the file in your preferred C++ compiler or IDE.

3. Compile and run the program.

4. The program will prompt you to enter:
   - Gross annual income
   - Filing status (`Single` or `Married`)
   - State of residence

   Notes:
   - Invalid inputs will prompt the user to re-enter valid information.
   - State and filing status inputs are not case-sensitive.

5. After valid information is entered, the program will display:
   - Gross annual income
   - Estimated federal income tax
   - Estimated state income tax
   - Total estimated taxes
   - Estimated take-home pay

6. The program will then terminate after displaying the tax summary.
